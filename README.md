# КПІ техвідділу — Ескада

Дашборд показників технічного відділу: вчасність, виробіток, якість.
Доступ лише для робочих акаунтів на домені компанії.

```
Excel з 1С  →  Google Drive  →  Apps Script  →  Vercel  →  браузер
                              (розбір і розрахунок)  (перевірка входу)
```

Тімлід кладе місячний експорт у папку на Drive. Apps Script щоранку його розбирає,
рахує показники й складає результат у файл `kpi_data.json` та в читабельну Google Таблицю.
Сторінка на Vercel показує ці числа тим, хто увійшов поштою компанії.

## Що в репозиторії

| | |
|---|---|
| `index.html`, `app.js` | сторінка дашборда |
| `api/data.js` | перевіряє вхід Google і забирає дані з Apps Script |
| `api/config.js` | віддає сторінці ідентифікатор клієнта Google |
| `apps-script/` | код для Apps Script — у Vercel не деплоїться, лежить для історії змін |

## Як рахуються показники

**Вчасність.** Задача вчасна, якщо закрита в межах 24 годин від постановки.
Субота й неділя не рахуються. Постановка після 17:00, до 8:00 або у вихідний
переноситься на наступний робочий день о 8:00.
Приклад: поставлено в пʼятницю 15:00 → дедлайн понеділок 15:00.
Показник командний. Поріг 55%, ціль 85%.

**Виробіток.** Сума планових годин закритих задач проти норми.
Норма = робочі дні місяця × 7 годин. Прогноз = годин зараз ÷ пройдені робочі дні × усі робочі дні.
Нижче 85% норми — нуль, від 85% до 99% — половина, від 100% — пропорційно.
Показник персональний.

**Якість.** З окремої таблиці. Персональна: поріг 96%, ціль 99%. Командна: поріг 96%, ціль 98%.

Виконавець «Максімова Катерина» виключений з розрахунків як помилка даних 1С.
Усі пороги й правила — у `apps-script/Config.gs`.

# Налаштування

Робиться один раз. Далі все працює саме.

## 1. Apps Script

1. Відкрити [script.google.com](https://script.google.com) → **Новий проєкт**, назвати «КПІ техвідділу».
2. Створити файли й вставити вміст з папки `apps-script/`:
   `Config.gs`, `Sla.gs`, `Parse.gs`, `Build.gs`, `Sheets.gs`.
3. Увімкнути розширений сервіс Drive: зліва **Служби** → `+` → **Drive API** → версія **v3** →
   ідентифікатор лишити `Drive`.
4. У `Config.gs` перевірити `FOLDER_ID` — це ідентифікатор папки на Drive із
   посилання виду `drive.google.com/drive/folders/XXXXX`.
5. Запустити функцію **`refreshData`**. Google попросить дозволи — дати.
   У журналі має зʼявитись рядок на кшталт `Оновлено: 17.11.2026 · закрито 233 · вчасність 61.4%`.
6. Запустити **`installTrigger`** — поставить щоденний запуск о 7:00.
7. Запустити **`showApiKey`** і зберегти ключ з журналу — він знадобиться у кроці 3.
8. **Розгорнути** → **Новий розгортання** → тип **Вебзастосунок**:
   - виконувати як: **я**;
   - хто має доступ: **усі** (саму адресу ніхто не знає, а без ключа вона нічого не віддає);
   - скопіювати адресу виду `https://script.google.com/macros/s/.../exec`.

## 2. Ідентифікатор клієнта Google

1. [console.cloud.google.com](https://console.cloud.google.com) → створити проєкт або взяти наявний.
2. **APIs & Services** → **OAuth consent screen** → тип **Internal** (лише домен компанії).
3. **Credentials** → **Create credentials** → **OAuth client ID** → тип **Web application**.
4. В **Authorized JavaScript origins** додати адресу майбутнього сайту на Vercel
   (наприклад `https://eskada-tech-kpi.vercel.app`) і, якщо буде своя, домен компанії.
5. Скопіювати **Client ID** виду `...apps.googleusercontent.com`.

## 3. Vercel

1. Підключити цей репозиторій: **Add New** → **Project** → вибрати `eskada-tech-kpi` → **Deploy**.
2. **Settings** → **Environment Variables**, додати чотири:

   | Назва | Значення |
   |---|---|
   | `GOOGLE_CLIENT_ID` | Client ID з кроку 2 |
   | `ALLOWED_DOMAIN` | `eskada-m.com` |
   | `GAS_URL` | адреса вебзастосунку з кроку 1 |
   | `GAS_KEY` | ключ із `showApiKey` |

   Необовʼязково: `ALLOWED_EMAILS` — пошти через кому для тих, хто поза доменом.
3. **Redeploy**, щоб змінні підхопились.
4. Повернутись у крок 2 і додати справжню адресу сайту в Authorized JavaScript origins,
   якщо вона відрізняється від тієї, що вписали наперед.

## Коли зʼявиться таблиця якості

У `Config.gs` вписати `QUALITY_SHEET_ID` — ідентифікатор Google Таблиці з посилання, і
`QUALITY_TAB` — назву аркуша. Очікувані колонки: **Виконавець**, **Якість %**,
**Перевірено робіт**, **З дефектом**. Відсоток приймається і як `98`, і як `0.98`.
Командна якість рахується як 1 − дефекти ÷ перевірені.

## Якщо щось не так

**Сторінка каже «Доступ лише для робочих акаунтів»** — увійшли особистою поштою.
Вийти й увійти робочою.

**«Не вдалося отримати дані»** — Apps Script недоступний або не той ключ.
Відкрити `GAS_URL?key=КЛЮЧ` у браузері: має віддати JSON.

**Числа не оновились** — у Apps Script відкрити **Тригери** й подивитись журнал виконань.
Найчастіша причина: у папці немає свіжого `.xls` або `.xlsx`.

**Треба перерахувати негайно** — запустити `refreshData` вручну або відкрити
`GAS_URL?key=КЛЮЧ&fresh=1`.
